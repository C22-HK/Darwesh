4 — Real navigation: Buy / Rent / Sell

Modeled on map.html's real segmented control, where Sell is genuinely a link to a different page (sell.html) — not an in-place mode switch.

Sell
Limitation, stated plainly: Buy/Rent are in-place mode switches, so the surface glides and stays. Sell is a real link to sell.html — clicking it glides the indicator for immediate visual feedback, then the browser navigates normally. No SPA interception, no delayed/faked navigation, no preventDefault. On the real site this means the glide is visible for a moment before the page unloads; there is no matching "content panel crossfade" for Sell because the panel doesn't exist on this page — it's a separate page.

5 — Reduced motion

With prefers-reduced-motion: reduce, the stretch/settle animation is skipped — the indicator jumps directly to its target and panels swap without the directional shift, per your instruction.
